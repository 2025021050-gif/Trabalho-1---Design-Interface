Programação Modular

A programação modular é uma técnica de desevolvimento de software que consiste em dividir um programa grande e complexo em partes menores, chamadas de módulos. Em vez de escrever todo o código em um único bloco, o problema principal é quebrado em suproblemas, e cada módulo fica responsável por executar uma função específica do sistema.

Principais Conceitos

  1. Móculo
  2. Interface
  3. Encapsulamento

A Programçaõ Modular fundamenta-se na ideia de criar componentes independentes que trabalham em conjunto. O elemento central dessa abordagem é o módulo, que funciona como um bloco de código autônomo, reunindo funções, variaveis e procedimentos específicos, garantindo que toda lógica necessária para um determinada tarefa fique organizada em um único local.
Para que esses módulos consigam se comunicar de maneira organizada, entra em cena a interface, atuando como "porta de entrada" do módulo, estabelecendo as regras e os caminhos pelos quais outros componentes do sistema podem interagir com ele, o módulo deixa disponivél apenas o necessário para seu uso, mantendo a complexidida intenra invisível.
Essa separação entre o que é visível e o que fica escondido é sustentada pelo conceito de encapsulamento. Graças a esse príncipio, lógica interna de funcionamento fica completamente restrita ao próprio módulo, dessa forma, qualquer desenvolvedor que precise utiliza-lo só precisa entender o que ele faz, sem mais detalhes técnicos de como a tarefa é executada.
